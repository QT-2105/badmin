# AI Escalation Rules

Version: 2026-06-09

Ask the owner before changing:

- runtime status lifecycle
- `JUST_FINISHED` cooldown semantics
- next-match scoring philosophy
- eligibility rules
- court lifecycle
- runtime DB sync strategy
- session completion finance behavior
- shuttlecock inventory movement rules
- session-scoped player architecture
- root navigation
- mobile/tablet runtime layout
- settings storage model

Escalation message must include:

- exact behavior being changed
- why current behavior is insufficient
- operational risk
- DB/migration risk if any
- safer smaller alternative

Do not escalate for:

- verified unused file cleanup
- typo fixes
- validation message improvements
- UI spacing fixes that preserve behavior
- docs/rules/prompts updates matching existing code

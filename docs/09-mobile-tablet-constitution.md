# Mobile And Tablet Constitution

Version: 2026-06-09

## Primary Devices

Primary runtime targets:

- tablet landscape
- smartphone portrait

Desktop is useful, but not the design center.

## Runtime Tablet Rules

Tablet landscape should keep these visible or one tap away:

- session top bar
- runtime stats
- all courts
- next-match suggestions
- refresh suggestions
- player list/payment review

Avoid large headers or oversized cards that push live controls below the fold.

## Runtime Mobile Rules

Mobile portrait must support:

- compact stats
- vertical court list
- bottom next-match panel
- full-screen player list
- large enough buttons for start/end/apply/cancel

## Touch Rules

- use large touch targets for runtime actions
- avoid dense tiny icon-only controls unless context is obvious
- keep scroll regions bounded so footers/actions are not covered
- avoid modal-heavy workflows during live operation

## Sidebar Rules

The sidebar must remain fixed on desktop/tablet. Collapsed state must remain stable across navigation.

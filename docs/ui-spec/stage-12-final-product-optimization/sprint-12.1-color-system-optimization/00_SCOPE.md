Status: IN PROGRESS

## Scope Lock

## Objective

Optimize the project color system for:

- light mode
- dark mode
- background and surface hierarchy
- text contrast
- border and divider hierarchy
- semantic tone readability
- focus, selection and overlay consistency

## Non-Goals

- no feature work
- no workflow changes
- no broad redesign
- no runtime palette normalization without a confirmed contrast issue
- no business, API, database, Prisma, repository, service, hook, query, mutation, payload, validation, route or permission changes

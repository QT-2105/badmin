# Sprint 12.7A Scope

## Goal

Final polish for App Shell and Dashboard presentation.

## App Shell Scope

- Sidebar surface.
- Active navigation state.
- Header border/background.
- Collapse affordance.
- Navigation spacing and icon consistency review.
- Main content background review.

## Dashboard Scope

- KPI hierarchy review.
- Section order review.
- Card density review.
- Color balance.
- Empty states.
- Financial summary.
- Inventory status.
- Recent session presentation.
- Light/dark and tablet source-level review.

## Not In Scope

- New player statistics.
- New chart or backend data.
- Dashboard query changes.
- Calculations.
- Routes, redirects or permission visibility.

# Sprint 7.7 - Responsive

Status: Planned

## Scope

Improve Finance responsive behavior for desktop, laptop, tablet landscape, tablet portrait, and mobile smoke usage.

## Allowed Presentation Changes

- responsive classes
- grid wrapping
- bounded overflow
- touch target sizing
- table/list horizontal scroll
- form stacking

## Not Allowed

- hiding important controls without an alternate visible path
- changing workflow
- changing data or handlers

# Sprint 7.6 - Feedback And Reporting States

Status: Planned

## Scope

Improve loading, empty, error, and action feedback presentation.

## Allowed Presentation Changes

- loading state component usage
- error state component usage
- empty state copy/presentation
- action error placement
- disabled visual states

## Not Allowed

- changing error source
- changing retry/fetch behavior
- changing validation source
- changing mutation behavior

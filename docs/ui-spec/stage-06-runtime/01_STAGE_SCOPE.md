# Stage Scope

Status: Planning / Audit

Source code changed: No

## In Scope

Stage 06 may improve only the visual and interaction presentation layer of:

- Runtime page frame
- Runtime header and control bar
- Court management area
- Court Card
- Người đang chờ
- Trận tiếp theo
- Lịch sử trận
- Tablet-first responsive layout
- Accessibility
- Visual consistency with Stage 01-05 UI platform

## Out Of Scope

Stage 06 must not change:

- algorithmic pairing
- queue order
- player eligibility
- player status transitions
- court lifecycle transitions
- match lifecycle transitions
- manual operator controls
- runtime persistence timing
- DB synchronization behavior
- route structure
- data fetching
- mutations
- permissions

## Success Definition

Runtime should feel cleaner, denser, more touch-friendly, and more consistent without changing how operators schedule, replace, apply, start, end, or record matches.

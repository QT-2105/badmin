## Read-Only Configuration

Read-only items may be documented or shown as static system information only if a future implementation plan explicitly allows it. They must not gain fake save controls.

## Missing Configuration

Notification, backup/restore, export/import, security settings, feature flags, and broader appearance settings are missing capabilities and must remain future scope.

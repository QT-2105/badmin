# Sprint 11.10 — Accessibility And Keyboard Scope

Allowed focus:

- ARIA labels.
- `aria-expanded`, `aria-selected`, `aria-describedby`.
- Focus-visible.
- Keyboard navigation.
- Reduced motion.
- Status text.
- Table/list semantics.

Not allowed:

- Changing action visibility.
- Changing permission checks.
- Changing route behavior.

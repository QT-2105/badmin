# Sprint 11.2 - Navigation Consistency

## Scope

Sprint 11.2 standardizes presentation-only navigation patterns across the app shell and page-level headers.

Allowed presentation targets:

- App sidebar visual states.
- Mobile navigation sizing and accessible names.
- Page header back-action placement.
- Back action visual consistency.
- Settings section navigation touch target and active-state presentation.

## Safety Lock

This sprint must not change:

- Routes.
- Redirects.
- Permission checks.
- Menu visibility logic.
- Deep links.
- Query parameters.
- Business logic.
- Runtime, finance, inventory, auth, permission, or settings behavior.

# Sprint 11.3 - Page Structure Consistency

## Scope

Standardize presentation structure across product pages without forcing every module into the exact same layout.

Reference order:

1. Page Header.
2. Toolbar / Filters.
3. KPI / Summary.
4. Primary Content.
5. Secondary Content.
6. Empty / Error / Loading feedback.

## Runtime Exception

Runtime keeps its approved operational flow:

- Next Matches.
- Courts.
- Waiting Queue.

No Runtime workflow or operational ordering is changed in this sprint.

## Safety Lock

Do not change:

- Component data.
- Handlers.
- Queries.
- Mutations.
- Zustand stores.
- Routes.
- Permissions.
- Runtime workflow.
- Finance or inventory calculations.

# Sprint 11.4 - Responsive Foundation

## Scope

Establish shared responsive presentation rules through existing UI primitives.

Standardized areas:

- Breakpoint usage.
- Container width.
- Horizontal padding.
- Grid columns.
- Gap.
- Stack behavior.
- Toolbar wrapping.
- Form/card density.
- Modal and drawer viewport bounds.
- Table and pagination containment.

## Safety Lock

Do not change:

- Business content priority.
- Component data.
- Handlers.
- Queries.
- Mutations.
- Stores.
- Routes.
- Permissions.
- Runtime, finance, inventory, auth, or settings logic.

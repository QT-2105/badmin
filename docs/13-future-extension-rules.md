# Future Extension Rules

Version: 2026-06-09

## Extension Principle

Extend Badmin by strengthening the current operational flow, not by turning it into another product category.

## Safe Extension Areas

- better dashboard summaries
- clearer finance period reports
- inventory stock warnings
- improved session completion review
- better next-match scoring knobs
- safer runtime recovery UI
- more responsive tablet/mobile polish
- controlled settings for existing behaviors

## Risky Extension Areas

Escalate before adding:

- memberships
- global player profiles
- subscriptions
- tournaments
- multiple locations
- warehouse bins
- accounting ledger
- audit replay
- role/permission architecture
- background realtime sync services

## Settings Rule

Settings should stay small and operational. Current settings are browser-local and include:

- auto-create court fee transaction
- auto-create shuttlecock usage transaction
- max court count per session

Do not add complex setting systems without a clear operational need.
